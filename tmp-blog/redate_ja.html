結論：Google フォトを Google Takeout で書き出すと、写真の撮影日は写真の中ではなく、横に並ぶ .json ファイルに入っています。そのため、ほかのアプリや PC に移すと、日付が「書き出した日」になったり、並び順がばらばらになったりします。直すには、json の日付を写真に戻す必要があります。コマンドを使わずに直すなら Redate（無料・アップロードなし）、慣れている人は ExifTool などの無料ツールでも直せます。

なぜ日付がおかしくなるのか

Takeout の zip を開くと、写真や動画の横に、同じ名前の .json ファイルが並んでいます。たとえば IMG_1234.jpg の横に IMG_1234.jpg.supplemental-metadata.json があります。この json に、Google フォトに表示されていた撮影日時と位置情報が書かれています。

  • ファイルの日付は「書き出した日」になる：Windows のエクスプローラーや多くのアプリは、写真の中の撮影日（EXIF）が無いと、ファイルの日付を使います。zip から取り出したファイルの日付は書き出した日なので、全部が同じ日に並びます。
  • 撮影日が写真の中に無いものが多い：スクリーンショット、LINE や SNS で保存した画像、動画、Google フォトで日付を直した写真は、写真の中に正しい日付がありません。正しい日付は json にしかありません。
  • json と写真の組み合わせが分かりにくい：長いファイル名は途中で切られ、同じ名前の写真は (1) の位置がずれ、編集した写真は -編集済み（英語の設定では -edited）が付きます。名前を見ても、どの json がどの写真のものか分からないことがあります。

つまり「json を消して写真だけ移す」と、日付の手がかりがなくなります。json は、日付を戻し終わるまで消さないでください。

まず確認：どの方法が合うか（4つの方法の比較）

数枚だけなら方法4でも足ります。何千枚もあるとき、名前の切れたファイルが多いとき、コマンドを使いたくないときは方法1が手早いです。

方法1：Redate で戻す（コマンドなし・アップロードなし）

Redate は、Google フォトの書き出し（Takeout）に撮影日を戻すための Windows アプリです（Daily Picks が作りました）。zip の中の json を読み、写真と動画を撮影日のまま zip に入れ直します。処理は PC の中だけで行い、写真をインターネットに送りません。

  1. takeout.google.com で「Google フォト」だけを選んでエクスポートし、届いた zip をダウンロードします（分かれて届いたら、すべてダウンロードします）。
  2. Microsoft Store で「Redate」を入れます（）。インストールせずに、ブラウザで Redate のページを開いても使えます。
  3. Redate を開き、Takeout の zip（展開したフォルダーでも可）を画面にドラッグします。zip が複数あるときは、まとめてドラッグします。
  4. 「見つかったもの」に、写真・動画の数と、日付が分かった件数が出ます。「撮影日を戻す」を押し、保存する場所を選びます。
  5. できた zip を右クリック ›「すべて展開」で開きます。写真と動画は撮影日の日付で展開され、JPEG 写真には撮影日が書き込まれています（EXIF）。

日付の決め方：json の撮影日 → json が無ければファイル名の日付（IMG_20240715_102030、Screenshot_2024-07-15 など）→ どちらも無ければそのまま、の順です。結果の画面に、それぞれの件数が出ます。
無料版と Pro：無料版では最初の100件の日付を戻します。Store 版の Redate Pro（買い切り・1,500円）では件数の上限がなくなり、年／月のフォルダーへの仕分けと、重複した写真の除外も使えます。

方法2：ExifTool で戻す（コマンドに慣れている人）

ExifTool は、写真の情報を読み書きする無料のツールです。json の日付を写真に書き込むコマンドがよく紹介されています。

  1. ExifTool の公式サイトから Windows 版を入れます。
  2. Takeout の zip を展開し、コマンドで json の photoTakenTime を写真の撮影日とファイルの日付に書き込みます。

細かく調整できる反面、名前が途中で切れた json や (1) の付いた写真は、そのままのコマンドでは組み合わせられないことがあります。件数が多いときは、終わったあとに日付が戻っていない写真が無いか確かめてください。

方法3：Google Photos Takeout Helper（gpth）を使う

GitHub で公開されている無料のツールで、Takeout の写真を整理し、日付を戻せます。名前の切れたファイルや重複にも対応しています。コマンドで動かすので、黒い画面の操作に抵抗が無い人向けです。

方法4：Google フォトの画面からダウンロードする（少ない枚数なら）

photos.google.com で写真を選んでダウンロードすると、json は付かず、元の写真が届きます。カメラで撮った写真なら写真の中に撮影日（EXIF）が入っているので、多くのアプリは正しい日付で並べます。ただし、スクリーンショットや保存した画像、動画は、ファイルの日付（ダウンロードした日）で並ぶことがあります。

うまくいかないとき

  • zip が何個にも分かれている：写真と、その json が別の zip に入っていることがあります。Redate にはすべての zip をまとめて入れてください。
  • 「日付が分からない」が多い：json が入っていない書き出し（アルバムだけ選んだなど）かもしれません。Takeout で「Google フォト」を丸ごと選んで書き出し直すと、json が付きます。
  • 展開したら日付がまた書き出した日になった：zip の中身を、別のアプリでコピーしたり、ブラウザで開いたりすると、日付が変わることがあります。エクスプローラーの「すべて展開」を使ってください。
  • 移したあとも並び順がおかしい：移した先のアプリが、写真の中の撮影日ではなく「追加した日」で並べていることがあります。並び順の設定を「撮影日」にしてください。

よくある質問

Q. json ファイルは消してもいいですか？
A. 日付を戻し終わってからなら消して構いません。戻す前に消すと、スクリーンショットや動画の正しい日付が分からなくなります。

Q. 写真の画質は落ちますか？
A. Redate は写真を作り直さず、そのまま入れ直します（JPEG は撮影日の情報を書き込むだけ）。画質は変わりません。

Q. 位置情報も戻せますか？
A. Redate では、位置情報が無い JPEG 写真に、json の位置情報を書き込めます（設定で選べます）。

Q. Mac でも使えますか？
A. Store 版は Windows 用です。ブラウザ版のページは Mac の Chrome・Edge でも開けます。
